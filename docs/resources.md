# Resources

A curated collection of links to help you build on the XRP Ledger.

## Official docs & tutorials

- [XRPL Tutorials](https://xrpl.org/docs/tutorials) — The full official tutorial series from xrpl.org — payments, tokens, DeFi and more.
- [xrpl.js API Reference](https://js.xrpl.org) — Complete API reference for the JavaScript SDK.
- [Learn XRPL](https://learn.xrpl.org/) — Courses and tutorials — fundamentals to advanced integrations.
- [All Official Code Samples](https://github.com/XRPLF/xrpl-dev-portal/tree/master/_code-samples) — Browse beginner-friendly repos from the official XRPL dev portal, organized by level.

## Dev tools

- [Testnet Explorer](https://testnet.xrpl.org) — Live view of the XRP Ledger Testnet — look up accounts, transactions, and blocks.
- [Download GitHub Subfolder](https://download-directory.github.io) — Grab any repo folder as a zip without cloning.

- [XRPL Commons](https://www.xrpl-commons.org/) — Non-profit advancing XRPL through open-source and grants.
